# AutoCenter API

## 📌 Descrição

A **AutoCenter API** é uma API desenvolvida em Java com Spring Boot, responsável por conectar todo o ecossistema de uma loja de auto center. O sistema permite a gestão de vendas, serviços de manutenção rápida (como troca de óleo) e agendamentos, integrando banco de dados, site (para clientes e beneficiários) e aplicativo mobile.

## 🚀 Funcionalidades

- 📦 **Gestão de Produtos**: Cadastro e listagem de peças e itens disponíveis para venda.
- 🛠 **Serviços de Manutenção**: Oferece serviços como troca de óleo e revisão rápida.
- 📅 **Agendamento de Serviços**: Permite que os clientes agendem manutenções no auto center.
- 🔐 **Autenticação e Autorização**: Implementação de JWT para segurança.
- 📊 **Dashboard Administrativo**: Consulta de vendas, serviços e clientes.

## 🛠 Tecnologias Utilizadas

- **Java 17+**
- **Spring Boot**
- **Spring Security & JWT**
- **JPA / Hibernate**
- **Maven**
- **Swagger para documentação da API**
